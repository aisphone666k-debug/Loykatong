# 🌕 ลอยกระทงกับแฟน (Loy Krathong with Love) 🌸

เว็บแอปพลิเคชันสำหรับลอยกระทงออนไลน์เคียงข้างกับแฟนหรือคนที่คุณรัก ตกแต่งกระทงได้อย่างอิสระ ติดรูปถ่ายคู่รัก เปิดเพลงวันลอยกระทง และลอยกระทงลงสู่แม่น้ำด้วยกันแบบเรียลไทม์ใต้แสงจันทร์วันเพ็ญ

---

## ✨ จุดเด่นและฟีเจอร์หลัก (Features)

1. **🎨 ห้องประดิษฐ์กระทงอิสระ (Krathong Studio)**
   - **ฐานกระทง 6 แบบ**: ใบตองดั้งเดิม, ดอกบัวหลวงบริสุทธิ์, ขนมปังเต่าน้อยรักษ์แม่น้ำ, กะลามะพร้าวเทียนหอม, โคนไอศกรีมพาสเทล, คริสตัลแก้วใส
   - **กลีบพับประดับ 6 แบบ**: กลีบผกากรองซ้อน 2 ชั้น, กลีบพับใบตองกลัดหมุด, ขอบทองฉลุลาย, กลีบกุหลาบหวาน, ประกายดาว
   - **ดอกไม้บูชา 7 สไตล์**: ดอกดาวเรืองมงคล, ดอกบัวหลวงชมพู, กล้วยไม้แคทลียา, ช่อกุหลาบคู่รัก, พวงมะลิหอม, ทานตะวันสดใส, ช่อบุปผารวม
   - **ธูปและเทียน 6 สี**: เทียนคู่หัวใจรัก (Twin Heart), เทียนทองดั้งเดิม, เทียนชมพูพาสเทล, เทียนขาวอโรมา, เทียนแดงนำโชค, เทียนทองเปล่งแสง พร้อมธูป 3 ดอกควันลอย
   - **เครื่องรางและของตกแต่งพิเศษ**: ป้ายไม้สลักชื่อคู่รัก, เหรียญบาทนำโชค, โบว์ริบบิ้นหวาน, ไฟแฟรี่วิบวับรอบกระทง, น้องหมีคู่รัก

2. **📸 อัพโหลดรูปคู่หรือรูปแฟนปักกระทง (Photo Uploader & Frame)**
   - อัพโหลดรูปคู่จากมือถือหรือคอมพิวเตอร์
   - กรอบรูป 4 สไตล์: กรอบรูปหัวใจสีทอง/ชมพู, กรอบโพลารอยด์, กรอบวงกลมเรืองแสง, กรอบแสตมป์วินเทจ
   - ปรับขนาดรูป (Zoom Slider) และหมุนองศาเอียงได้ตามใจชอบ
   - รูปจะถูกปักบนก้านไม้เสียบกระทงอย่างประณีต

3. **🎵 เครื่องเล่นเพลงวันลอยกระทงในตัว (BGM Player)**
   - เสียงสังเคราะห์ด้วย Web Audio API ความคมชัดสูง ไม่ต้องโหลดไฟล์ภายนอก
   - **Track 1**: เพลงรำวงวันลอยกระทง (ระนาดเอก & ฉิ่งฉับ & ดนตรีไทยประยุกต์)
   - **Track 2**: ลอยกระทงหวานซึ้ง (Romantic Piano & Acoustic)
   - **Track 3**: ธรรมชาติริมแม่น้ำ (เสียงสายน้ำไหลเอื่อยและจิ้งหรีดราตรี)
   - วิดเจ็ตแผ่นเสียงหมุนวนสุดคลาสสิก พร้อมปุ่มเปลี่ยนเพลงและเปิด/ปิดเพลง

4. **🌊 ลอยกระทงคู่กันแบบเรียลไทม์ (Synchronized Realtime River Experience)**
   - **ระบบห้องคู่รัก**: สร้างห้องส่วนตัว (เช่น `LOVE-8899`) และแชร์ลิงก์ให้แฟนได้ในคลิกเดียว
   - **เชื่อมต่อ P2P ผ่าน WebRTC (PeerJS)**: เล่นข้ามอุปกรณ์หรือข้ามเน็ตได้โดยตรง
   - **รองรับ Multi-tab BroadcastChannel**: ทดสอบ 2 แท็บพร้อมกันบนคอมเครื่องเดียวกันได้ทันที
   - **กระทงคู่รักดึงดูดเข้าหากัน (Love Attraction Physics)**: เมื่อกระทงลอยลงสู่แม่น้ำเจ้าพระยา กระทงของทั้งคู่จะค่อยๆ ลอยเคียงคู่ชิดกัน พร้อมฟองหัวใจลอยขึ้นมา
   - **ปุ่มโต้ตอบแบบเรียลไทม์**:
     - ❤️ ส่งหัวใจลอยฟุ้ง
     - 🎆 จุดพลุฉลองรักบนท้องฟ้า
     - 🏮 ปล่อยโคมลอยคู่รักขึ้นสู่พระจันทร์
     - 🌸 โปรยกลีบดอกไม้ลงน้ำ
     - 💬 ส่งข้อความกระซิบรักถึงแฟน ("รักแฟนที่สุด", "ขอให้อยู่ด้วยกันทุกปีนะ")
   - **📷 ถ่ายรูปที่ระลึก (Souvenir Keepsake)**: เซฟภาพกระทงคู่ใต้แสงจันทร์พร้อมกรอบที่ระลึกวันลอยกระทง โหลดเป็นไฟล์ภาพลงเครื่องได้ทันที

## ✈️ สำหรับคู่รักที่อยู่คนละประเทศ (Long-Distance Relationship - LDR)

เนื่องจากคุณและแฟนอยู่คนละประเทศ เครือข่าย Wi-Fi/เน็ตมือถือจะอยู่คนละเครือข่ายกัน ระบบจึงได้รับการอัปเกรดให้รองรับ **Global Cloud Relay (MQTT over Secure WebSockets)** และ **Global STUN WebRTC** ทำให้ส่งข้อมูลข้ามประเทศได้แบบเรียลไทม์ 100% ไม่ติดบล็อก Firewall!

### วิธีเอาเว็บขึ้นออนไลน์เพื่อให้แฟนที่อยู่ต่างประเทศกดเข้าลิงก์ได้ทันที (ใช้เวลา 1 นาที ฟรี 100%):

#### 🌟 วิธีที่แนะนำและง่ายที่สุด: Netlify Drop (ลากแล้ววาง)
1. เปิดเบราว์เซอร์ไปที่ **[https://app.netlify.com/drop](https://app.netlify.com/drop)**
2. เปิด File Explorer ในเครื่องของคุณ ไปที่โฟลเดอร์ `I:\ExpensMonitor\`
3. **ลากโฟลเดอร์ `loy-krathong` ทั้งโฟลเดอร์ไปปล่อยลงในหน้าเว็บ Netlify Drop**
4. ภายใน 10 วินาที คุณจะได้ลิงก์เว็บไซต์แบบ HTTPS ฟรีตลอดชีพ เช่น `https://romantic-krathong-xyz.netlify.app`
5. ส่งลิงก์นี้ให้แฟนที่อยู่ต่างประเทศเปิดผ่านมือถือ (iPhone/Android) หรือคอมพิวเตอร์ได้ทันที!
6. สร้างห้อง รับรหัสห้อง (เช่น `LOVE-8899`) แล้วลอยกระทงคู่กันแบบเรียลไทม์ได้เลย 🌕❤️

## 🚀 วิธีเปิดใช้งานในเครื่อง (Local Testing)

### วิธีที่ 1: ดับเบิลคลิกไฟล์ `run.bat` (ง่ายที่สุด)
- ดับเบิลคลิกที่ไฟล์ `run.bat` ในโฟลเดอร์นี้
- โปรแกรมจะเปิดเซิร์ฟเวอร์และเปิดหน้าเว็บขึ้นมาบนเบราว์เซอร์ให้อัตโนมัติที่ `http://localhost:3000`

### วิธีที่ 2: รันผ่าน Node.js
```bash
node server.js
```
จะมีแจ้งเตือน IP สำหรับเปิดบนมือถือของแฟนในวง Wi-Fi เดียวกันด้วย เช่น:
- คอมพิวเตอร์: `http://localhost:3000`
- มือถือ: `http://192.168.1.xxx:3000`

### วิธีที่ 3: เปิดไฟล์ `index.html` โดยตรง
- สามารถดับเบิลคลิกเปิดไฟล์ `index.html` ด้วย Google Chrome, Microsoft Edge, หรือ Safari ได้ทันที!
